# Commands

## Objective

Print the commands. Somebody has asked what they can write at you, so the whole
answer is the list.

## Steps

- List every skill you have been given, one per line: the command that loads it
  and, after a dash, what it is for in a few words. Your briefing names each
  skill with its command; that is the list.
- Order them as your briefing does. Do not invent, rename, or leave any out.
- Say the marker once, at the top, in a line: how a command is written and that
  it can go anywhere in a message.
- Nothing else. No preamble, no offer to explain further, no summary of what
  you can do in general - that is a different question, and answering it here
  is what makes this list hard to read.
- Where you have been given no skills at all, say exactly that in one line
  rather than apologising or listing your tools instead.

## Shape

    Write a command anywhere in a message, like ::review.

    ::review - how this workspace reviews a change
    ::handover - the note the next shift reads
    ::plan - propose a plan and wait for approval before acting
